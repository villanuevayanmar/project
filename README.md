# PayTrack — Payroll Management System

PayTrack is a static classroom prototype made with HTML and CSS. It demonstrates the login page, a payroll dashboard layout, section links, and logout navigation.

## Project files

- index.html — login page
- dashboard.html — payroll workspace preview
- style.css — shared layout, colors, responsive rules, and focus states
- DESIGN.md — the visual and content decisions for the project

## Required page flow

1. Open index.html.
2. Enter any non-empty username and password.
3. Select Login to open dashboard.html.
4. Select Log out or Return to login to go back to index.html.

The login form uses browser-required fields only. It does not verify accounts. The input fields are not named form values, so the entries are not added to the dashboard URL or saved.

## Current dashboard content

The employee register is intentionally empty: this project has 0 employee records. No payroll period or payroll rules have been configured, so the page does not show made-up salaries, deduction rates, or totals.

## Prototype limits

- No real account authentication.
- No employee record storage or retrieval.
- No salary, deduction, or take-home-pay calculation.
- No secure handling of real employee information.

Do not enter real passwords or employee data into this demonstration.

## HTML and CSS topics

- Forms, labels, inputs, buttons, links, navigation, sections, and tables.
- Flexbox and CSS Grid for page layout.
- Fixed, relative, and absolute positioning.
- Responsive media queries and keyboard focus states.

Open index.html in a browser to start.
