# PayTrack - Payroll Management System

A simple payroll management website made with HTML and CSS only.

## Project files

- `index.html` - Login page.
- `dashboard.html` - Payroll dashboard.
- `style.css` - Styles shared by both pages.

## Required navigation

1. Open `index.html`.
2. Enter any text in the username and password fields.
3. Select **Login** to open `dashboard.html`.
4. Select **Log out** in the sidebar to return to `index.html`.

## Dashboard contents

- Payroll overview: total employees, gross payroll, deductions, and net payroll.
- Employee records.
- Payroll summary.
- Common deductions.

All names and amounts shown are sample data for the school project.

## Important limitation

This is a static HTML and CSS demonstration. The form only checks that both fields are filled in before navigating to the dashboard. It does not verify real accounts, calculate salaries, save payroll records, or protect private employee information.

## HTML and CSS topics used

- HTML forms, labels, inputs, buttons, links, sections, and tables.
- CSS colors, margins, padding, borders, flexbox, and media queries.
- CSS positioning: fixed sidebar, relative dashboard heading, and absolute heading label.

Open `index.html` in a browser to start.
